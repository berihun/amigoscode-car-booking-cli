This application is developed for admins of a company that runs car rental businesses. 
The application is developed using Java SE. It is  a Java CLI project with the following tech stack:
1. Java JDK 25
2. Maven
3. PostgreSQL

How to configure and run the application:
  1. First, pull the project from GitHub:
https://github.com/berihun/amigoscode-car-booking-cli
  2. Open the project in intellij Ide/idea
  3. Run the database script to create the schema and add seed data
  4. Finally, run the app from the menu and check
